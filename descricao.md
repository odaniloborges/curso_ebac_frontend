# Orientação a Objetos com JavaScript

## Sobre o Projeto

Este projeto reúne exemplos práticos dos principais conceitos de programação orientada a objetos (POO) utilizando JavaScript.

## Principais Conceitos Abordados

- **Abstração:** Modelagem de entidades do mundo real em objetos.
- **Herança:** Criação de classes e subclasses, com reutilização de atributos e métodos.
- **Encapsulamento:** Proteção e organização dos dados e comportamentos dos objetos.
- **Polimorfismo:** Métodos que se adaptam conforme o contexto do objeto.
- **Criação de Objetos:** Utilização de notação literal, funções construtoras e classes.
- **Verificação de Tipos:** Diferença entre tipos primitivos e instâncias de objetos, além da verificação de instâncias personalizadas.
- **Manipulação de Atributos:** Técnicas para acessar, modificar e proteger atributos.

## Tecnologias Utilizadas

- **JavaScript:** Implementação dos conceitos de POO.

## Como Usar

1. Clone o repositório.
2. Abra o arquivo `oo.js` em seu editor de código.
3. Explore e adapte os exemplos conforme sua necessidade.

## Sugestões de Aprendizado

- Crie suas próprias classes e objetos.
- Pratique herança, encapsulamento e polimorfismo.
- Teste diferentes formas de manipulação de atributos.
